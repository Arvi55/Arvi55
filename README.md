### ⚡ About Me

I'm a Computer Science (Data Science) student who got hooked on one idea: **don't make the LLM guess — make it reason, use tools, and stay grounded in real data.**

That's the thread running through everything I build — agents that decide what to look up, chain multiple steps together when a question needs it, and refuse to hallucinate an answer when the data isn't there.

- 🔭 Currently building **agentic AI systems** with LangChain / LangGraph
- 🧠 Into multi-step reasoning, tool-calling agents, and RAG pipelines
- 📊 Backed by a strong data foundation — SQL, Power BI, Pandas, Scikit-learn
- 🌱 Prepping for GATE DA while shipping real projects on the side
- 💬 Ask me about agent architecture, LangGraph, or anything data

### 🧩 Featured Build

**[VINDICA — AI-Powered Employee Intelligence System](https://github.com/Arvi55/VINDICA-AI-Powered-Employee-Intelligence-System)**
An agent that lets HR ask plain-English questions about employees and get answers grounded in real data — not guesses. Multi-hop tool reasoning, database-grounded responses, zero hallucination by design.
